Archive · 2025 – 2026

Experiments in how agents learn, remember, and prove what they know.

Everything under “Frozen” is archived and read-only — kept because it is still true, not because it is maintained. The live work is listed first, and it is a short list: the organisation's main active project is lora-kernel, and agentvcs has been revived beside it. Every public repository that is not archived is listed on the front page, with its status; every archived one is listed at the end of this page. Several of the ideas below are carried forward in it. What the twenty-six of them added up to is written down once, in the thesis.

Agents that modify themselves are easy to build and hard to trust. Everything here attacks the second half of that sentence — versioning an agent's evolution so a human can review it, reading a model's internal workspace to catch a memory it was tricked into keeping, or constraining a small model at the decoder so invalid output is not discouraged but impossible.

Each experiment is labelled by how much evidence stands behind it — including the ones where the evidence went against us.

Everything here comes out of an ongoing conversation between Matias Molinas and Ismael Faro — the ideas, the architecture, and the code. The repositories are where those conversations got tested.

lora-kernel Live

What if an expert were the specialist who knows how to use the library, not the textbook?

An operating layer for specialized local AI agents: one small resident model, many specialists — each an adapter, a library of notes it has learned to navigate, and its own scoped tools — and a router that abstains to a frontier model. The flagship. The numbers, including what has not passed, are on the front page.

Sep 2026 → agentvcs Live Prototype

Version control for live-patched agent systems: change your harness while it runs and still know what worked.

Revived — validation in progress. One commit carries code, goal, model pins and trace together, so a change an agent system makes to itself while running is versioned beside the one your team makes in git, and the two can be merged. It was folded into evolving-agents and frozen; it is its own repository again, and active.

 Oct 2026 → coclea-sr Live Results

What does an agent workload look like when truth comes from somewhere it cannot reach?

A 1995 biophysics hypothesis taken from mathematics, through a falsification of its own model, to a gated set of falsifiable statements about ear disease. The gates are not opinions about whether the numbers look right: the analytic value comes from a module forbidden to import the code under test.

 Aug 2026 → hemo-verified Live Results

And what does it look like when the truth is not derivable, and a judge is all you have?

The companion workload, and the one that tests the argument rather than repeating it. A frontier model was handed twelve fabricated results and nine subtly defective ones and caught all of them, twice — so the claim narrows to the one that survives: a model can judge a task, but it cannot generate one with a known answer, and a judge that is right every time still hands you no ledger, no freeze and no reproduction command.

 Aug 2026 → evolving-agents Reproducible

The agent loop is solved. What happens after you fork a session is not.

A plugin for the Claude Agent SDK. Fork branches a session and nothing rejoins the branches — no merge, no diff between two sessions, nothing that refuses to promote an agent whose eval regressed. This began in 2025 as eighteen thousand lines with three test functions; ten thousand of them were deleted the day the SDK made them unnecessary. Not archived, and not where the work is: the repository also holds the ai-os subtree, last changed 2026-09-06, and a frozen copy of agentvcs.

 Jul 2026 → evolving-memory Results Moved

What if an agent's memory consolidated itself the way sleep consolidates yours?

A trajectory engine that chunks execution traces, connects them and curates what survives. Its headline idea — indexing a component by what it is for as well as what it is — was rebuilt and measured at 80% either way. No advantage, published anyway.

Archived — readable, not maintained

token-trie Reproducible Archived

What if a small model could not emit invalid syntax, because the decoder refused to let it?

Every legal instruction is pre-tokenized into a trie of token IDs and the sampler's valid-next set is masked at each step. A 350M-parameter model plays Tetris in a browser tab, fully offline. Masking logits needs the sampler, which an API-backed SDK does not hand you — which is why this one could not follow the others.

 May 2026 → sleep-harness Results Archived

What if you could catch a poisoned memory by watching which concepts light up inside the model?

An interpretability firewall for agent memory. Reads the residual stream through a Jacobian lens to flag injected instructions that are lexically identical to benign text, and to scan third-party adapters for trojans before they mount. Needs the weights, so it stayed where it is.

 Jul 2026 → skillos_robot Prototype Archived

What if the robot were just a device driver for a language model?

A slow vision-language brain plans at roughly one hertz while a reactive controller drives motors at twenty, over a bytecode link to an ESP32.

 May 2026 → qa Prototype Archived

What if your test suite told you what it had quietly stopped checking?

Every assertion is fingerprinted and diffed across runs, so a check that silently disappeared surfaces as a finding. Passing exploratory sessions get frozen into deterministic scripts.

Every archived repository — twenty-five, all public and read-only

The write-ups above cover the ones with a finding to report. This is the whole list, from gh repo list EvolvingAgentsLabs on 2026-10-08, with where each one went if it moved.

  • agent-command-center A Claude Code plugin for managing teams of parallel agents through tmux.
  • agent-forge Notebooks from mid-2025 exploring agent generation by LoRA fine-tuning; never engineered past them.
  • agent-loadout A design specification with no source code; both halves were already built in evolving-memory and skillos’s system-control plugin.
  • ai-os An agent-based operating system on a vendored QM base. Moved to evolving-agents/ai-os, history intact, 2026-09-06.
  • autoresearch-mini A researcher agent that searches for better synthetic training data instead of better architectures, after karpathy/autoresearch.
  • evolving-memory A trajectory engine for agent memory. Moved to evolving-agents/packages/memory.
  • evolving-robot A 2D robot that rewrites its own care skills. Moved to evolving-agents/demos/robot.
  • gemma4nanoloop An autonomous engineering crew on a local Gemma 4 12B; a fork of ismaelfaro/nanoLoop.
  • jlens-harness An agent testbench that reads the model’s internal workspace. Merged into sleep-harness.
  • llm_os Token-trie constrained decoding for local models. Moved: the live kernel is in token-trie.
  • llmos A browser-native markdown agent workspace, superseded by skillos. Not related to llm_os.
  • llmunix-dreamos Memory consolidation for Claude Code, modelled on sleep.
  • llmunix-marketplace The LLMunix kernel plugin. Superseded by skillos_plugin, the same plugin renamed.
  • llmunix-starter A pure-markdown operating-system template; its kernel duplicates skillos_plugin.
  • mjswan A fork of ttktjmt/mjswan: MuJoCo simulations in the browser on WebAssembly.
  • nanoLoop A fork of ismaelfaro/nanoLoop, a minimal task harness. Its reconciler moved into agentvcs as an example.
  • qa A QA plugin that fingerprints every assertion, so a check that quietly disappeared surfaces as a finding.
  • skillos An operating system written in markdown: skills as programs, traces as logs.
  • skillos_plugin The SkillOS kernel as a Claude Code plugin.
  • skillos_robot A robot as a device driver for a language model, over a bytecode link to an ESP32.
  • skillos_systemcontrol_plugin Audits, scoring and controlled evolution for SkillOS projects.
  • skillos_x_mobile CareCompanion: skills, memory and dreams on Gemma 4, a Kaggle hackathon entry.
  • skillos_x_robot A patrol-robot demo of skills, memory and dreams in a 2D simulation.
  • sleep-harness An interpretability firewall for agent memory, read through a Jacobian lens.
  • token-trie Constrained decoding by a trie of token IDs: a 350M model plays Tetris and cannot emit invalid syntax.
